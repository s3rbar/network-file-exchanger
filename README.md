# network-file-exchanger
## A CLI program that allows to exchange files and messages on the local network

# WARNING: Not properly tested yet! DO NOT use in environments with sensitive information!

# To test on your own machine
1. Make sure you have Ruby Interpreter installed
2. Clone the repository
3. Use 'ruby app.rb' command

# To download a version with an .exe file
1. Clone the repository
2. Visit this repository to convert -> https://github.com/ardatetikexe/Standalone-Ruby
3. Once converted, launch 'program.exe' file
